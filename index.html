В dashboard_data.json нет блока "total" — запустите compute_total.py.
NOW — байесовская конверсия по кумулятивным неделям, приор Beta(a0,b0), N=50k, вердикт по правилам выше (нед. 1 / 2 / ≥3). Предупреждение — когда вердикт расходится с пробой Amazon (порог 80%). Динамика на основном dim (без сегмента first_discovery); блок «как в Amazon» — за последний доступный срез.
TOTAL — все эксперименты из дампа Amazon (название, ASIN, даты и статус — оттуда же, как во вкладке NOW); из ручного лога решений продукта (result_exps.csv) берётся только колонка Result (A/B). Waiting Start — Amazon ещё не начал показывать версии покупателям (VALIDATING/LOCKED и т.п.) — не считается ни в "экспериментов всего", ни в динамике запусков, тест фактически не стартовал. In Progress — тест идёт. Waiting Decision — Amazon уже закончил тест (COMPLETE/CANCELED), а решения продукта в файле ещё нет. Decided — решение зафиксировано (A или B), неважно завершился тест сам или его остановили вручную, это один терминальный статус. Win Rate и Avg Uplift CR считаются только по Decided-экспериментам (аплифт — только по победителям, B).
